### ⚡ Featured Projects (Showcase)

#### 🏛️ Prison Sentence Duration Predictor
* **Domain:** Natural Language Processing (NLP) / Deep Learning
* **Impact & Methodology:** Engineered an automated pipeline to scrape 6,208 criminal indictments from the Indonesian Court System (SIPP-PN). Benchmarked LSTM, BiLSTM, and IndoBERT architectures.
* **Key Results:** The **BiLSTM configuration outperformed other models**, achieving a **Mean Absolute Error (MAE) of 5.32**. Integrated model interpretability using **Integrated Gradients** to extract feature attribution maps, deployed via a **React + Flask** web app.
* *Tech Stack:* `Python`, `TensorFlow`, `IndoBERT`, `Selenium`, `Flask`, `React.js + Vite`

#### 💼 SECURA - Integrated Financial & Admin Ecosystem
* **Domain:** Enterprise Automation / Full-Stack System
* **Impact:** Designed, built, and deployed an end-to-end admin system to transition fragmented manual workflows into a secure, single-integrity framework.
* **Key Results:** **Optimized corporate operational efficiency by ~75%**. Secured system via Role-Based Access Control (RBAC), adaptive password hashing (Werkzeug), and automated cloud backups.
* *Tech Stack:* `React.js + Vite`, `Flask REST API`, `SQLAlchemy ORM`, `MariaDB`, `Nginx`

#### 🐟 [SeaFest - Fish Freshness & Classification](https://github.com/SeaFest-Capstone/Machine-Learning)
* **Domain:** Computer Vision / Mobile Deployment
* **Impact:** Built during the Bangkit Academy cohort as a primary core developer to determine fish types and decay levels.
* **Key Results:** Achieved **~98% classification accuracy** on freshness detection (4,880 images) and **~96% accuracy** on species transfer learning using InceptionV3 (2,582 images).
* *Tech Stack:* `Python`, `TensorFlow`, `InceptionV3`, `TensorFlow Lite`
